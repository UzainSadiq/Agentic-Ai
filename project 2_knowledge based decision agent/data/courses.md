# Courses
## Artificial Intelligence
Recommended background: Python programming, basic statistics, introductory data structures.
Topics include search, machine learning, neural networks, NLP, and AI agents.
## Agentic AI
Recommended background: Python, basic LLM concepts, prompt engineering, APIs.
Topics include tool calling, RAG, vector databases, LangGraph workflows, and agent evaluation.
## Database Systems
Topics include relational databases, SQL, normalization, transactions, and indexing.
