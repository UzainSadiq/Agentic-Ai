



# Agentic-Ai
A collection of Agentic AI projects developed to explore autonomous AI agents, LLM integration, RAG pipelines, tool calling, automation, and real-world AI workflows using Python and modern AI frameworks.

**Overall Course Outcome**

Through these projects, the portfolio demonstrates practical understanding of how to build AI systems that can:

Understand → Reason → Decide → Act → Retrieve → Collaborate → Validate → Respond

The projects cover the major building blocks of modern Agentic AI, including LLM integration, AI agents, tool calling, RAG, LangGraph, stateful workflows, multi-agent collaboration, APIs, and user-facing applications.

Together, these implementations represent a progression from basic agent concepts to practical, intelligent, and interactive Agentic AI applications.

The first projects focus on understanding the foundation of Agentic AI and how an AI agent differs from a traditional LLM application. The system receives a user's goal, reasons about the task, decides what needs to be done, and produces an appropriate response.

Key concepts: AI Agents, LLMs, prompting, reasoning, decision-making, agent workflows.

**2.  Tool-Using AI Agent****

This project introduces tool calling, allowing an AI agent to interact with external functions instead of relying only on its internal knowledge. The agent analyzes the user's request and determines whether a specific tool is required.

Examples include calculators, APIs, information retrieval, and other utility functions.

Key concepts: Tool Calling, Function Calling, Agent Routing, Action Selection, LLM + Tools.

**3.  Retrieval-Augmented Generation (RAG) Agent****

This project demonstrates how an AI agent can use an external knowledge source to provide more grounded responses. Instead of depending entirely on the LLM's training knowledge, the agent retrieves relevant information and uses it while generating an answer.

The approach is particularly useful for course notes, documents, organizational knowledge, and domain-specific information.

Key concepts: RAG, embeddings, document retrieval, knowledge grounding, contextual generation.

**4.  Edu Agent AI**

Edu Agent AI is an educational AI assistant and student-success platform. It combines Agentic AI with an interactive dashboard to help students study more effectively.

The system provides an AI study assistant, academic insights, progress analytics, learning resources, and personalized study planning. It demonstrates how an agent can understand a student's needs and provide useful recommendations rather than simply answering questions.

Key concepts: Educational AI, personalized assistance, RAG, recommendations, dashboards, AI study planning.

**5.  Multi-Agent Problem Solving System**

This project demonstrates a multi-agent architecture, where several specialized AI agents work together to solve a complex problem.
Instead of asking one agent to perform every task, responsibilities can be divided between agents such as a researcher, analyst, solver, reviewer, and coordinator. Their outputs are then combined into a final solution.

**6.  Telegram Agentic AI Assistant****
This project brings Agentic AI into a real-world messaging environment through a Telegram chatbot.
A user sends a request through Telegram. The Lang Graph-based agent analyzes the request, decides whether it requires an LLM response, knowledge retrieval, or a tool, validates the result, and generates the final response.

**7. 🎓 EduAgent — Agentic AI Student Assistant**

Edu Agent is a complete Agentic AI-powered educational assistant designed to help students with learning, academic progress, study planning, and personalized recommendations.

Unlike a basic educational chatbot, EduAgent combines AI reasoning, student information, learning resources, progress analysis, and planning into a single intelligent system. The application provides an interactive dashboard where students can communicate with the AI assistant and receive personalized academic support
